# Product Context

Personal OS — личная PWA для ежедневного планирования, простого журнала тренировок и контроля питания. Приложение рассчитано на одного пользователя и работает на Mac, iPhone и iPad через единый FastAPI и SQLite.

## Принципы продукта

- быстрый ввод без перегруженных форм;
- одна понятная ежедневная картина вместо сложной аналитики;
- спокойный адаптивный интерфейс в визуальном языке `MyLifePlanner`;
- данные хранятся централизованно в SQLite и доступны всем устройствам через один API;
- новые модули остаются частями модульного монолита.

## Текущий релиз

`v0.4` включает:

- Planner со сроком, цветным выбором начального приоритета и автоматическим повышением приоритета;
- Fitness с календарём месяца, одной тренировкой в день, редактированием, удалением и отметкой употребления креатина;
- Nutrition с дневными целями, редактируемой историей белка и калорий и кольцами прогресса;
- пудрово-пастельный адаптивный дизайн на основе локального проекта `MyLifePlanner`.

Полная офлайн-синхронизация, авторизация и облачная инфраструктура в текущий scope не входят.
